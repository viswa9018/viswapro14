HTML/CSS Absolute Positioning
Aim

Create an HTML page that demonstrates the use of absolute positioning.

Task

Complete the CSS in **index.html** so that the <aside> element is absolutely positioned relative to the <body>.

Do not change the existing HTML structure or content.

Requirements

Your solution must:

Set the body element to position: relative.

Set the aside element to position: absolute.

Set the aside element's right property to 30px.

Set the aside element's top property to 50px.

Preserve the supplied HTML content and structure.

Grading
Requirement	Points
Body uses position: relative	10
Aside uses position: absolute	15
Aside uses right: 30px	10
Aside uses top: 50px	10
HTML structure and content preserved	5
Total	50
Submission

Commit and push your completed index.html to your GitHub Classroom repository.

Automated tests will run when you push your changes.

Expected result

The "Enter to win a free ticket!" box should appear near the upper-right area of the page, positioned independently from the normal document flow.
